A font invented for Bloom Matrix

Three custom wordmark directions, each "keeping the matrix in mind." The chosen one gets built into real drawn letterforms (SVG logotype + display lettering for headlines).

A — Full Dot-Matrix

Every letterform constructed from grid dots — the wordmark literally IS a matrix. Distinctive and ownable; best as display/logo lettering, paired with a clean sans for body text.

blm matrix

B — Bloom Grotesk (hybrid)

A confident geometric sans where only the key glyphs are custom: the two "o"s become perfect matrix cells (one holding the coral seed), the "x" is the matrix crossing point. Subtle — premium at every size.

Bloom Matrix

C — Editorial Serif + Seed

Keeps the editorial serif voice from the hero, with a custom coral "seed" full stop as the matrix cell. Quietest option — the mark does the talking, the wordmark stays elegant.

To be honest about "inventing a font": we can genuinely draw a custom display logotype + headline lettering (as SVG/font file) for whichever direction you pick — that's real and ownable. A full text typeface with every weight is a months-long type-design project, so body copy would stay on a licensed font (e.g., Inter).
